# ☀️ Sticky Weather V57

[logo](docs/logo.png)

**reTerminal Sticky → Minimalist e-paper weather station**

Firmware for Seeed reTerminal Sticky (ESP32-S3) that turns it into an e-paper weather station. Ultra-low power and 100% browser flashing.

## ✨ Features

- 🌤️ Current weather + 3-day forecast (Open-Meteo API)
- 🌡️ Indoor temperature with SHT40 sensor
- 🔋 60min deep-sleep, WiFi only when needed (18% battery saving)
- 🌙 Moon icon when going to sleep
- 💻 Direct flashing from Chrome/Edge, no install needed
- 🎨 Sticky Weather logo optimized for e-paper

## 🚀 Flash now

**👉 https://estebangel-crypto.github.io/sticky-weather/**

1. Connect Sticky via USB-C (hold BOOT if needed)
2. Press INSTALL and select the COM port
3. Wait until 100% Done!
